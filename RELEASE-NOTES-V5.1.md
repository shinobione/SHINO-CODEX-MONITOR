# SHINO // CODEX MONITOR V5.1.0 — Historical Release Notes

This is the last stable version before the Codex Periscope rebrand.

## Features
- One Windows widget for Codex ChatGPT account quotas and local task activity.
- Circular 5-hour and weekly gauges, explicit resets, source and freshness.
- Native animated activity indicator and confirmed terminal events.
- Read-only, unofficial local JSONL observation; active Desktop tab not guaranteed.
- Tray, history, customizable appearance, optional alerts and Windows startup.

## Installation
Download `SHINO_CODEX_MONITOR_V5_1_WINDOWS.zip` from the
[official V5.1 release](https://github.com/shinobione/SHINO-CODEX-MONITOR/releases/tag/v5.1.0).
Extract, close the running widget and execute `INSTALLER-V5.1.bat`.
The installer verifies SHA-256 and runs 98 quota and 46 activity tests before replacing the EXE.

## Limitations
The application is unsigned and not affiliated with OpenAI. No passwords or
tokens are read, and no paid model API calls are made. Local session logs may
not correspond to the currently visible Codex Desktop thread.

For the successor brand see [Codex Periscope V5.2](BRANDING-V5.2.md).
