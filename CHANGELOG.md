# Changelog — CODEX PERISCOPE

## 5.2.0-preview.1 — English radar rebrand (development)

- Rebrands the public-facing Windows utility as **Codex Periscope**, with independent-app disclaimer.
- Native radar/periscope ICO in multiple resolutions, animated teal radar activity sweep and dark navy radar palette.
- English-only UI, menus, history, quota/freshness states, error messages and diagnostics; English month names with local times.
- Adds `CODEX-PERISCOPE.exe`, `INSTALLER-V5.2.ps1`, `UNINSTALL-V5.2.ps1`, new ZIP package and English README.
- Keeps V5.1 configuration and quota history in their existing internal folder; preserves the single-instance mutex.
- Adds user-confirmed Windows startup migration, removes obsolete V4/V4.5 prompt text from the new app.
- Remains **a preview**: Windows CI, installer upgrade/rollback and published updater compatibility must pass before release.

## 5.1.0 — SHINO // CODEX MONITOR (published October 19, 2026)

- Unified quota and local Codex activity widget, optional task notifications, time and effort metadata when exposed.
- Native Windows installation, SHA-256 validation and locally retained preferences/history.
